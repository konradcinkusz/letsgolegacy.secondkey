\section{Klauzule kontraktu bench nopCommerce}\label{app:klauzule}

Tabela wymienia wszystkie 76~klauzul pliku \path{contract/contract.yaml} bench nopCommerce
(sekcja~\ref{sec:bench}) w~kolejności z~pliku: 61~rodzaju \texttt{must} i~15~rodzaju
\texttt{never}. Kolumna „Zakres \texttt{when}” podaje metodę, wyrażenie regularne ścieżki
i~wyrażenia parametrów zapytania (w~większości sondy \texttt{probe}) w~postaci, w~jakiej
odczytuje je parser YAML; klauzula bez \texttt{when} obejmuje każde żądanie. Tytuły są
przepisane z~pliku bez zmian, a~asercje, uzasadnienia \texttt{why} z~numerami reguł
R01--R46 planu ruchu i~proweniencja (u~wszystkich klauzul \texttt{origin: designed},
\texttt{status: accepted}) pozostają w~pliku źródłowym.
